# 家维录

家庭资产护照与维保账本。

把家里的设备、型号、序列号、购买信息、保修、票据、维护计划和真实服务支出，整理成一份可以长期查阅的家庭档案。无需账户、无广告，记录默认保存在你的设备上。

## 你可以记录什么

- 设备、铭牌、型号与序列号
- 购买日期、价格与保修期限
- 发票、保修凭证和维修照片
- 家庭维护计划、服务商和实际费用
- 年度维护支出、到期风险与 PDF 报告

免费版可以完整管理 8 件资产；需要无限资产、票据与服务凭证、成本洞察和 PDF 报告时，可在 App 内选择 Pro。中国区 2026 年 9 月 1 日至 25 日终身 Pro 临时价 ¥6，9 月 26 日恢复 ¥198，年度 Pro ¥68/年，实际价格以 App Store 最终展示为准。

## 产品原则

- 不要求注册账户
- 无广告、无第三方分析、不跨 App 追踪
- 资产记录、照片和票据默认只保存在设备上
- Pro 购买由 Apple App Store 处理，并支持恢复购买

计算结果仅供家庭资产与维护记录参考，不构成维修、保险、税务或法律意见。

本仓库托管家维录的公开产品页、隐私政策与支持页面，使用 GitHub Pages 发布。
