帮助与支持

照片和票据会上传吗？

不会。家维录只处理你主动选择的照片，并保存在设备本地数据库中。

如何建立维护计划？

在“资产”中打开一件设备，选择“为此资产添加维护计划”；也可以在“计划”中浏览全部专业模板。首次添加计划时，App 会请求本地通知权限。

提醒没有出现？

请前往“设置 → 通知 → 家维录”确认权限已开启，并确认计划的下次到期日仍在未来。

如何恢复 Pro？

在总览右上角打开“家维录 Pro”，点击页面底部的“恢复购买”，并确认设备登录了原购买 Apple ID。

如何导出报告？

Pro 用户可在“洞察”中选择“导出 PDF 报告”。报告由设备本地生成，再交给系统分享面板处理。

如何删除数据？

可在资产详情中删除资产及关联记录；卸载 App 会删除本机上的全部数据。

提交问题前

请准备 iOS 版本、家维录版本和完整复现步骤，并先隐藏票据、序列号等私密信息。我们不会要求你提供 Apple ID 密码、付款卡号或未打码的家庭资料。
